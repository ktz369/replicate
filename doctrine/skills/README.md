# doctrine/skills — salinan terdokumentasi doctrine MAJESTA

Salinan (copy-first) dari skill hasil de-Hermes-ify di profil pi runtime
(`~/.pi/agent/skills/`, hasil adopsi CONS-01 dan koreksi CONS-03):

- `memory-architecture/` — T0–T4 doctrine, T0 hygiene, milik ASTRAL
- `trinity-memory-placement/` — aturan penempatan memori per layer
- `trinity-session-routing/` — anchor order + routing sesi Trinity
- `trinity-verification-gates/` — preflight/post-action verification gates
- `compound/` — promosi memori terverifikasi → `knowledge/` OKF bundle
- `compound-refresh/` — audit OKF bundle (stale/overlap/kontradiksi)

## Sumber kebenaran runtime tetap profil pi

File di sini adalah **salinan terdokumentasi**, bukan sumber eksekusi.
Runtime selalu memuat skill dari profil pi (`~/.pi/agent/skills/`); repo ini
menyimpan salinan sebagai bagian dari repo of record agar stack bisa
direkonstruksi (prinsip copy-first MAJESTA — profil sumber tetap utuh sampai
cutover identitas MAJ-14). Sinkronisasi dilakukan manual/periodik; kalau ada
perbedaan, **versi di profil pi yang berlaku**.
